
最近フェールオーバークラスタを構築していた際に検証ウィザードでノードを追加しようとして
「サーバーの管理者特権がありません」というエラーが発生しました。
エラーの原因が分からず1日半くらい時間を消費したので、
次の自分に向けて備忘録を残そうと思います。

# 構成
AD、DNSサーバー
サーバーA（クラスタ）←こっちでクラスタの検証をしようとするとサーバーBに対して管理者特権がないと出る
サーバーB（クラスタ）

# 解決
サーバーA側の仮想スイッチを再作成したら解消しました。
検証する前に「\\\サーバー名\admin$」で相手側のサーバーにアクセスできない場合は
管理者特権がないエラーが発生するかもしれないのでサーバーの設定を確認した方がいいかもしれないです。

# その他にやったこと
## DomainAdministratorに権限付与
Active Directory ユーザーとコンピューターからサーバーBに対しての権限を付与
サーバーA、Bに対していローカルセキュリティポリシーのユーザー権限の割り当てからネットワーク経由でのアクセスの権限を確認（すでにAdministratorには権限付与されていた）
## Kerberos認証の確認
```
サーバーBのチケットがあるか
klist
リセット
klist purge
```
```
時刻同期
w32tm /query /status
```
## DNSの確認
```
nslookup サーバー名
```
## ファイアウォールの確認
一旦ファイアウォールをOFFにして検証できるか確認
## GPOの確認
アクセスを拒否するGPOがないか確認
